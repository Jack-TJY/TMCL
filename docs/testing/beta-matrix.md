### 后续改进（不阻塞发布，计划 beta.3）

- Fabric API 安装失败的提示里显示了完整的编码后 Modrinth 网址，过长难读，只显示主机名即可。
- 失败提示的“打开资源页”应直接进入“浏览与安装”，并预先搜索“Fabric API”。
- 资源页一键新建实例默认是“原版”加载器，应自动选中该资源支持的加载器。
