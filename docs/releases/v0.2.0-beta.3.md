# TMCL v0.2.0-beta.3 发布说明

TMCL 的第三个 Beta 版本改进了从资源页新建实例和重试 Fabric API 下载的操作。反馈问题时，可在“设置 → 存储 → 导出诊断信息”生成 zip 并附在反馈中。[问题反馈](https://github.com/Jack-TJY/TMCL/issues)

> TMCL 是非官方启动器，与 Mojang Studios 和 Microsoft 没有关联。

## 新增

- 从资源页为 Mod 一键新建实例时，TMCL 会根据资源的正式版文件预选加载器，并列出兼容的游戏版本。[#206](https://github.com/Jack-TJY/TMCL/pull/206)

## 修复

- Fabric API 下载失败时，错误提示显示主机名和可用的 HTTP 状态码，省略冗长的编码路径和查询参数。
- 点击“打开资源页”会进入原实例的 Mod“浏览与安装”，自动搜索 Fabric API。即使中途切回“已安装”或改搜其他 Mod，再次点击也会重新搜索。[#206](https://github.com/Jack-TJY/TMCL/pull/206)
- 更新 SQLite 相关依赖及异步任务执行器，修复依赖审查报告的问题。[#208](https://github.com/Jack-TJY/TMCL/pull/208)

## 已测试

Windows 10 开发构建连接真实 Modrinth，为 Fabric API 一键新建实例时自动选中游戏版本 26.3 和 Fabric 0.20.1，“创建并下载”按钮可用。另用 1.20.1、1.12.2 和 26.3 原版实例验证按键同步，在游戏按键菜单中核对了正向和反向结果。

实际前端配合模拟的 HTTP 503 验证了错误提示、原实例定位和重复搜索。Windows 10 从 Beta.2 原位升级后可启动，原有设置和两个实例的配置文件校验值一致。Ubuntu 24.04.5 的 deb 和 AppImage 均能在 X11 和 Wayland 下打开窗口。macOS 磁盘映像的版本与 arm64 架构已核对。真实 Fabric API 下载失败后的重试仍待实测。跨平台补齐必需前置（X1）的 5 项离线测试通过，真实安装仍待合适样本。[Beta 测试矩阵](https://github.com/Jack-TJY/TMCL/blob/main/docs/testing/beta-matrix.md)

## 已知问题

- 直连联机首次连接可能需要十几秒，如首次失败可重试，持续失败时可改用樱花穿透。
- Forge 1.7.10 无模组时可能在主菜单崩溃。旧版启动器（beta.1 及更早）读取已迁移的皮肤库时会显示为空，共用皮肤库的安装应统一升级到 beta.2 或更新版本。
- macOS 安装、启动与卸载的实机验证仍待补测。暂不支持自动更新，新版本需要手动下载。[此前已知问题](https://github.com/Jack-TJY/TMCL/blob/main/docs/releases/v0.2.0-beta.2.md#已知问题)

## English

The third beta improves loader selection when creating an instance from a mod and makes it easier to retry a failed Fabric API download. To report a problem, open an issue and attach the ZIP from Settings → Storage → Export diagnostics. [Report an issue](https://github.com/Jack-TJY/TMCL/issues)

> TMCL is an unofficial launcher and is not affiliated with Mojang Studios or Microsoft.

**Changes.** Creating an instance from a mod now preselects a compatible loader. Fabric API download errors show the host and available HTTP status code. “Open resources” returns to the original instance’s mod browser and searches for Fabric API again, even after you switched tabs or changed the search. SQLite and async executor dependencies were also updated.

**Test coverage.** A Windows 10 development build selected Fabric 0.20.1 for Fabric API on game version 26.3. In-game key binding menus confirmed sync from 1.20.1 to 1.12.2 and 26.3, and back from 1.12.2 to 1.20.1. Error messages and repeated searches were checked with a simulated HTTP 503. The Windows 10 upgrade from Beta.2 preserved the settings and both instance configurations. On Ubuntu 24.04.5, the deb and AppImage both opened windows under X11 and Wayland. The macOS disk image was checked for version and arm64 architecture. Recovery from a real Fabric API download failure still needs testing. Cross-platform dependency installation still needs a real-world sample.

**Known issues.** A direct connection may need a retry. Forge 1.7.10 can crash at the main menu without mods. Installations sharing a migrated skin library should all run beta.2 or later. macOS installation, launch and removal still need hardware testing. Updates require a manual download.

**Downloads.** Download and extract the ZIP for your platform from the table above. Windows includes an EXE installer, macOS includes a DMG, and Linux includes both an executable AppImage and a deb package. SHA-256 checksums for the three ZIPs appear on the GitHub release page.
