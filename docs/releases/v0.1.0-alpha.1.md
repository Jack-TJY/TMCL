TMCL 的第一个 Alpha 预览版。可以下载并启动我的世界 Java 版（含模组加载器），使用微软正版、外置登录或离线账号。这是测试版本，可能存在问题，欢迎在 [Issues](https://github.com/Jack-TJY/TMCL/issues) 反馈。

> TMCL 是非官方启动器，与 Mojang Studios 和 Microsoft 没有关联。

## 功能

- **游戏下载**：正式版、快照、远古版本一键下载，自动补全依赖库与资源文件；支持分片并发、断点续传、失败重试。Forge、NeoForge、Fabric 通过 BMCLAPI 镜像加速，失败自动回退官方源。
- **Java 管理**：自动探测本机 Java，按游戏版本选择；没有合适的 Java 时自动下载官方运行时。
- **账号**：微软正版登录（设备码，令牌存入系统密钥库并自动续期）、authlib-injector 外置登录（如 LittleSkin）、离线账号（仅限本地测试）。
- **实例**：每个实例独立的游戏目录；重命名、复制、分组排序、导入导出 `.tmclpack`。
- **模组加载器**：Forge、NeoForge、Fabric、Quilt 一键安装，可在实例详情中更换。
- **启动**：一键启动、游戏日志窗口（可搜索、复制、导出）、崩溃提示、强制结束。
- **界面**：Windows 11 风格界面，深浅色，Win11 磨砂玻璃 / Mica 与 macOS 毛玻璃窗口材质，自定义背景与透明度，可拖拽排布的首页组件，任务中心，简体中文与英文。

## 已测试

Windows 10 实机：a1.0.4、1.7.10、1.12.2、1.16.5、1.20.1、26.3 与四种加载器共 18 个组合；Windows 11 与 Ubuntu 24.04 虚拟机：安装、启动 1.20.1、卸载。详见 [Alpha 测试矩阵](https://github.com/Jack-TJY/TMCL/blob/main/docs/testing/alpha-matrix.md)。

## 已知问题

- Forge 1.7.10（不装模组时）进入主菜单开始放音乐时可能崩溃，这是 Forge 自身的问题，原版 1.7.10 不受影响。
- 在部分虚拟机的虚拟显卡上，26.x 版本可能黑屏（有声音）。
- macOS 版本未经实机测试，也没有 Apple 签名，首次打开方法见 [README](https://github.com/Jack-TJY/TMCL#安装)。
- 首页“快捷操作”组件在默认大小下需要滚动。
- Linux 上 WebKit 会在 `~/.local/share/io.github.jack-tjy.tmcl` 写入少量缓存，卸载后不会自动删除。
- 暂不支持自动更新，新版本需要手动下载。

## English

The first alpha of TMCL. It downloads and launches Minecraft: Java Edition (including mod loaders) with Microsoft, authlib-injector or offline accounts. This is a test build and may have issues; please report them in [Issues](https://github.com/Jack-TJY/TMCL/issues).

> TMCL is an unofficial launcher and is not affiliated with Mojang Studios or Microsoft.

**Features:** one-click game download with chunked, resumable downloads and mirror fallback; automatic Java detection and download; Microsoft (device code), authlib-injector and offline accounts; isolated instances with copy and `.tmclpack` import/export; Forge, NeoForge, Fabric and Quilt installation; launch, game log window and crash detection; a Windows 11–style UI with dark mode, Mica/acrylic and macOS vibrancy, custom backgrounds, a draggable home page and a task center, in Simplified Chinese and English.

**Known issues:** Forge 1.7.10 without mods may crash when the menu music starts (a Forge bug); 26.x may show a black screen on some virtual GPUs; the macOS build is untested and unsigned (see the README for how to open it); no auto-update yet.

Checksums are in `SHA256SUMS.txt`.
